Renude · 2026

An agent harness for Renude's AI-native skincare assistant.

I engineered the harness behind Renude's AI-native revamp of its skincare assistant and shipped it as a drop-in plugin. Most of the work went into what keeps an agent trustworthy: grounding, fallbacks, and a hardened server.

The challenge

A skincare assistant has to get details right, keep working when the model doesn't, and run inside other people's storefronts without exposing its prompts or inviting abuse. The revamp needed an agent that was useful and trustworthy at the same time.

Architecture

The assistant runs as a browser-side agent loop on the OpenAI Responses API. It orchestrates 27 client-side tools and streams over SSE through a stateless Vercel proxy that owns the prompts and tool schemas.

What I built

Grounding

No numbers from model prose

Cards are emitted by tool runs, so every figure the user sees is traceable. I also measured the provenance of the profile fields each tool read.

Reliability

Retry, then fall back

When the model fails, the harness retries and then falls back to a deterministic offline intent router, so the assistant keeps working.

Security

A hardened server

Server-owned prompts and tool schemas, input validation, and per-IP rate limits. I also added voice input.

Distribution

Shipped as a plugin

A Shopify-style plugin behind a two-file adapter and a kill switch, with ranking, compatibility, and rule engines built in React 19.

How I build

Across agents, recommenders, and hardware, the same three rules keep showing up.

  1. Rule 01

    Ground the model.

    Figures come from tools and data, not model prose. At Renude, every number is a card emitted by a tool run. At Giving Connection, every match ships with its reasons.

  2. Rule 02

    Keep the critical path deterministic.

    ML personalizes; rules decide what can't fail. Nura's dosing lives in firmware, and Renude's assistant falls back to an offline intent router.

  3. Rule 03

    Start with people, then instrument.

    Nura's requirements came from 100+ user and expert interviews. Smart Match shipped with feedback capture, so the next version starts from evidence.
